= Edit Service Display Details 
ifndef::env-site,env-github[]
include::_attributes.adoc[]
endif::[]

The following information that displays for a service can be edited:

* Description
* Instance visibility
* Version visibility
* Icon image
+ 
Image files must be .png 

To edit the information that displays for a service:

. From the catalog, click a service card.
+
The Catalog management page displays the information of the service.
. From the *Actions* options, select *Edit display details*.
. To change the description, enter a new asset description in the *Description* field.
. To change the instance visibility, select an option from the drop-down list.
. To change the version visibility, select an option from the drop-down list for the corresponding version
. To change the icon, click *Upload file* and select an approved image file type.
. To cancel the changes, click *Cancel*.
. To save the changes, click *Save*.
